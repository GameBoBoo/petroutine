# User Flow และหน้าจอ

## เริ่มต้น

Landing → สมัคร/เข้าสู่ระบบ → สร้างบ้านหรือใส่รหัสเชิญ → เพิ่มสัตว์เลี้ยง → เปิด Quick Add → เลือกเทมเพลตหรือสร้างกิจวัตร → ตรวจงานใน Today

## งานประจำวัน

Today → กรองงานของฉัน/ทุกคน สัตว์ และสถานะ → กดเสร็จทันที หรือเปิดหมายเหตุ → Undo ได้ 8 วินาที

ทางเลือกต่อหนึ่งงาน: Skip พร้อมเหตุผล, เลื่อนเวลาเฉพาะครั้ง, เปลี่ยนผู้รับผิดชอบเฉพาะครั้ง หากข้อมูลถูกสมาชิกคนอื่นเปลี่ยนก่อน ระบบแจ้ง conflict และโหลดข้อมูลล่าสุด

## บันทึกนอกตารางและสุขภาพ

เพิ่ม → บันทึกการดูแลนอกตาราง หรือข้อมูลสุขภาพ → กรอกข้อความ/ตัวเลขเอง → รายการปรากฏใน Pet Timeline และ Activity โดยไม่สร้างงานอนาคต

## ตรวจสอบข้อมูล

- ปฏิทิน: ดู occurrence จริงและ projection สูงสุด 42 วัน
- สัตว์เลี้ยง: ภาพรวม กิจวัตร สุขภาพ Timeline
- ประวัติการเปลี่ยนแปลง: กรองสมาชิก/สัตว์/การกระทำ/วันที่ และเปิดดู before/after เพื่อทราบว่าใครเปลี่ยนข้อมูลอะไรเมื่อใด
- ประวัติ: รายการ task ที่ complete/skip; care/health และ archived context ดูผ่าน Timeline/Activity

## Navigation

Desktop มี Sidebar และปุ่ม “เพิ่มรายการ” ชัดเจน มือถือมี 5 รายการตามลำดับ: วันนี้, ปฏิทิน, เพิ่ม, สัตว์เลี้ยง, เพิ่มเติม โดย “เพิ่มเติม” รวมกิจวัตร ประวัติ ประวัติการเปลี่ยนแปลง บ้าน และตั้งค่า

## ถังขยะของบ้าน

บ้านของเรา → เจ้าของบ้านเลือก “ย้ายบ้านไปถังขยะ” → พิมพ์ชื่อบ้านให้ตรง → บ้านหายจากสมาชิกทุกคนแต่ข้อมูลไม่ถูกลบ → เจ้าของเปิดถังขยะและกด “กู้คืนบ้าน” เพื่อกลับมาใช้งานพร้อมข้อมูลเดิม
