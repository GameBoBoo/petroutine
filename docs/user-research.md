# User Research Plan

## เป้าหมาย

ตรวจสอบว่าผู้ดูแลสุนัขและแมวมีปัญหาเรื่องการลืมงาน การทำงานซ้ำ หรือการสื่อสารในครอบครัวจริงหรือไม่

## กลุ่มตัวอย่าง

- เจ้าของสุนัขหรือแมว 5–8 คน
- ควรมีผู้ดูแลหลายคนอย่างน้อย 3 คน
- ควรมีทั้งคนที่ใช้ Application จัดการงานและคนที่ใช้แชตหรือกระดาษ

## คำถามสัมภาษณ์

1. ในบ้านมีใครช่วยดูแลสัตว์เลี้ยงบ้าง?
2. แต่ละวันต้องทำกิจกรรมอะไร?
3. เคยลืมหรือทำงานซ้ำหรือไม่?
4. ปัจจุบันใช้วิธีสื่อสารกันอย่างไร?
5. อยากเห็นข้อมูลอะไรเมื่อเปิดระบบ?
6. ใครควรมีสิทธิ์แก้ไขตาราง?
7. ประวัติแบบใดมีประโยชน์?
8. อะไรจะทำให้เลิกใช้ระบบ?

## สิ่งที่ต้องบันทึก

- ปัญหาที่เกิดบ่อย
- กิจกรรมที่สำคัญที่สุด
- จำนวนผู้ดูแล
- วิธีแก้ปัญหาปัจจุบัน
- ข้อจำกัดด้านเวลาและความสะดวก
- คำพูดสำคัญของผู้ใช้โดยไม่เปิดเผยข้อมูลส่วนตัว

## กติกาความเป็นส่วนตัว

- ขออนุญาตก่อนบันทึกการสัมภาษณ์
- ไม่เก็บชื่อจริงหากไม่จำเป็น
- ไม่เก็บข้อมูลสุขภาพสัตว์จริงใน Demo โดยไม่ได้รับอนุญาต
- ใช้ข้อมูลสมมติในการพัฒนา
