# ประสบการณ์ใช้งาน PetRoutine

อัปเดต 7 พฤศจิกายน 2569 ดู [รุ่นและหลักฐาน](current-release.md) คู่กับเอกสารนี้

## การอ่านและจัดการรายการ

หน้าปกติเน้นข้อมูล ไม่มีปุ่มจัดการซ้ำทุกแถว ปุ่ม “จัดการรายการ” อยู่ใน header ของส่วนที่มีสิทธิ์จัดการ ใกล้ปุ่มเพิ่ม ใช้สีส้มและไอคอนแก้ไข เมื่อเปิดเป็นสีเขียว “เสร็จสิ้น” และแสดง edit/delete ตามสิทธิ์ กดเสร็จสิ้นเพื่อซ่อนเครื่องมือระดับรายการ

ใช้กับกิจวัตร ข้อมูลสัตว์ เหตุการณ์สุขภาพ Passport เช็กอิน และ care entry ใน Timeline รายการไม่แสดงเครื่องมือให้ผู้ที่ไม่มีสิทธิ์ หน้าเปลี่ยนเป็นโหมดอ่านเมื่อเปลี่ยนหน้าหลักหรือบ้าน

ข้อยกเว้นคือ **บ้านและสมาชิก**: Owner เห็นลบบ้านโดยตรง ไม่มีปุ่มจัดการรายการ ต้องพิมพ์ชื่อบ้านและยืนยันก่อนลบ ยกเลิกแล้วไม่ส่งคำขอลบ

## งานทำซ้ำกับงานครั้งเดียว

Sidebar กิจวัตรและแท็บกิจวัตรรายสัตว์แสดงเฉพาะ weekly/interval ยอดนับในภาพรวมสัตว์ไม่รวม once การค้นหา/กรอง/pagination ใช้เฉพาะกิจวัตร งานครั้งเดียวยังแสดงตามวันใน Today/Calendar ผ่าน occurrence engine เดิม

## AI และการใช้ API

Today จำการเปิดเครื่องมือและสรุปล่าสุดแยกตามผู้ใช้/บ้านในหน่วยความจำระหว่างสลับหน้า คำตอบที่รออยู่ยังเก็บต่อได้ ดูซ้ำไม่เรียก AI ใหม่ มีเวลาอัปเดต และกด “อัปเดตสรุป” เพื่อขอข้อมูลใหม่ Full reload หรือ logout ล้าง cache นี้

นำบันทึกด้วยข้อความ/AI draft และเตรียมคุยกับสัตวแพทย์ออกจาก UI แล้ว ใช้ฟอร์มบันทึกปกติ แชต AI และสรุปส่งต่อได้ ดู [AI guide](ai-phase-11.md)

## รายงานและฟอร์ม

Vet Report มีโลโก้ PetRoutine ใช้พื้นขาว/เส้นเทาบาง รูปแบบส่งออก A4 ลดหัวเรื่อง ตัวอักษร และช่องไฟ พร้อม margin และ export copy ที่แยกจาก preview ให้ PDF ไม่ขึ้นกับขนาด viewport หรือธีม

Dropdown ใช้ SelectField, วันเวลาใช้ Bangkok, mutation สำคัญยังตรวจทานและยืนยัน ใช้คำว่า “ลบ” แต่ backend เป็น soft archive รักษาประวัติและสิทธิ์เดิม Health/care ของสัตว์ที่ archive แล้วแก้ไม่ได้จน restore parent

การกู้คืนผ่าน API และรอบตรวจใน Course ให้ดู [API](api-design.md), [Testing](testing.md) และ [Delivery](delivery/README.md) เอกสารใน superpowers เป็นแผนย้อนหลัง ไม่ใช่รายการ UI ปัจจุบัน
