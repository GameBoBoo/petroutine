# Phase 11 — Grounded AI Care Assistant (Optional)

อัปเดต 25 ตุลาคม 2026 — มีผู้ช่วยจับประเด็นในหน้า Today, สรุปส่งต่อการดูแล, สรุปเตรียมพบสัตวแพทย์, แบบร่างบันทึกจากข้อความธรรมชาติ และ Chatbot สำหรับคำถามเฉพาะ

## ประสบการณ์หลัก

- Today เริ่มเป็นการ์ดปิด ไม่เรียก AI หรือโหลดสถานะ/Alert จนกว่าผู้ใช้กด “เปิดเครื่องมือช่วยดูแล” หลังเปิดจะแสดงรายการเปลี่ยนแปลงจาก Wellness Alert ที่คำนวณด้วยกฎของระบบ พร้อมเปิดข้อมูลต้นทางในหน้า Pets ได้ การเปิดเครื่องมือไม่ใช้โทเคนโมเดล
- เมื่อผู้ใช้กดสรุปส่งต่อหรือเตรียมพบสัตวแพทย์ ระบบเรียก AI **หนึ่งครั้งต่อการกด** จากข้อมูลชุดย่อไม่เกิน 70 รายการ คำตอบมี source IDs ที่ตรวจสิทธิ์แล้วและกดเปิดบันทึกได้ ไม่มีการลองเรียกโมเดลซ้ำอัตโนมัติ
- Quick Add รับข้อความธรรมชาติแล้ว AI เตรียมแบบร่างบันทึกการดูแลหรือสุขภาพ ผู้ใช้ต้องตรวจและแก้ฟอร์มเดิม ก่อนกดยืนยันบันทึกตามขั้นตอนปกติ AI ไม่มีสิทธิ์บันทึกเอง
- บ้านที่ยังไม่เปิด AI หรือสมาชิกยังไม่ยินยอมเห็นทางไปหน้าตั้งค่าแทนการส่งข้อมูลให้ผู้ให้บริการ บนหน้า Today เปิดแชตจากปุ่ม “ถาม AI เพิ่มเติม” ในการ์ดผู้ช่วย ส่วนหน้าอื่นยังใช้ปุ่มลอยได้
- เมื่อเชื่อมต่อ AI ไม่ได้หรือผู้ให้บริการตอบผิดรูปแบบ จะแสดงสถานะขัดข้องและยังใช้การบันทึกปกติได้ ผู้ใช้เป็นผู้ตัดสินใจว่าจะกดลองใหม่เมื่อใด

## สิ่งที่ผู้ใช้ทำได้

หลังล็อกอินมีปุ่ม **ถาม AI** มุมขวาล่าง เลือกสัตว์เลี้ยงรายตัวหรือ **ทุกตัวในบ้าน** และช่วงย้อนหลัง 7, 30 หรือ 365 วันได้ คำถามเกี่ยวกับข้อมูลที่ PawRoutine เก็บ เช่น โปรไฟล์ งาน/กิจวัตร เช็กอิน บันทึกการดูแล บันทึกสุขภาพ สมุดสุขภาพ และ Alert/follow-up ที่ยังเปิดอยู่ คำตอบแสดงชื่อสัตว์เลี้ยงและอ้างอิงบันทึกต้นทางที่เปิดดูได้ ข้อมูลเหตุการณ์ตามวันที่อยู่ในช่วงที่เลือก ส่วนโปรไฟล์ สมุดสุขภาพ และกิจวัตรปัจจุบันอาจอยู่นอกช่วงนั้น

ข้อมูลที่ส่งต่อคำขอจำกัดสูงสุด 240 facts และคำถามไม่เกิน 500 ตัวอักษร ควรเลือกช่วงและสัตว์เลี้ยงให้แคบลงเมื่อต้องการรายละเอียดมาก ประวัติสนทนาอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น เปลี่ยนสัตว์เลี้ยงหรือบ้านแล้วเริ่มบทสนทนาใหม่

## การเปิดใช้และการตั้งค่า

- Server ต้องตั้ง `PAWROUTINE_AI_ENABLED=true`, `AI_API_KEY`, `AI_MODEL` และ `AI_BASE_URL` ใน `.env` ที่ Git ไม่ติดตาม Docker Compose ส่งตัวแปรนี้ให้ web container แล้วรัน migration ตอนเริ่มงาน บ้านใหม่ยังปิด AI จนเจ้าของเปิดที่ Settings
- สมาชิกยินยอมครั้งเดียวต่อบ้าน ถอนความยินยอมใน Settings ได้ API ตรวจสิทธิ์บ้านและ consent ทุกคำขอ
- ค่าเริ่มต้นของโควตาแอปคือ 10 คำขอต่อผู้ใช้ต่อชั่วโมง เครื่องทดสอบนี้ตั้ง `PAWROUTINE_AI_HOURLY_LIMIT=0` เพื่อปิดโควตานี้ชั่วคราว โควตาของ Provider และขีดจำกัดคำถามยังมีผล
- Provider ที่ตรวจล่าสุดคือ Gemini 3.5 Flash Lite ผ่าน endpoint แบบ OpenAI-compatible ห้ามใส่ API key ในเอกสารหรือ commit `.env`

## Guardrails และข้อมูลที่เก็บ

- AI สรุปจากข้อมูลที่อ่านได้และเตรียมแบบร่างเท่านั้น ไม่มีสิทธิ์แก้บันทึกหรือสร้าง Alert เอง การบันทึกแบบร่างต้องผ่านฟอร์มและการยืนยันของผู้ใช้ AI ไม่วินิจฉัยโรค คำนวณขนาดยา หรือสั่งหยุดยา
- Server จำกัดบริบทตามสิทธิ์และขนาด ตรวจรูปแบบ JSON และรับ source ID เฉพาะรายการที่อยู่ในบริบทที่ส่งไป หาก Provider ล้มเหลว ระบบส่วนอื่น เช่น Baseline, Alert, Dashboard และ Vet Report ยังทำงานได้
- Request audit เก็บเฉพาะ metadata เช่น ผู้ใช้/บ้าน/สัตว์เลี้ยง ช่วงวันที่ โมเดล สถานะ และ source IDs ไม่เก็บคำถามหรือคำตอบ
- คำตอบด้านสุขภาพเป็นการอธิบายข้อมูลที่บันทึกไว้ ไม่ใช่คำแนะนำทางสัตวแพทย์
