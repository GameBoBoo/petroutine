# Problem Statement

## ชื่อโครงการ

PawRoutine — ระบบจัดการกิจวัตรการดูแลสุนัขและแมว

## ปัญหา

สมมติฐานของโครงการคือสถานะงานที่ไม่ชัดเจนและข้อมูลที่กระจายในแชต กระดาษ หรือความจำ อาจทำให้ผู้ดูแลตรวจว่าใครทำงานใดแล้วได้ยาก และอาจเกิดการลืมหรือทำงานซ้ำ เช่น ให้อาหาร เติมน้ำ พาเดินเล่น และทำความสะอาด ยังต้องตรวจเหตุการณ์และสาเหตุจากผู้ใช้จริง การมีผู้ดูแลหลายคนไม่ได้เป็นสาเหตุที่พิสูจน์แล้วโดยลำพัง อ่าน [หลักฐานภายนอกและข้อจำกัด](delivery/problem-evidence.md) กับ [แผนตรวจผู้ใช้](delivery/user-validation.md)

## กลุ่มผู้ใช้

ผู้ใช้ระยะแรกคือเจ้าของสุนัขและแมวที่ดูแลสัตว์ร่วมกับสมาชิกในครอบครัว โดยเริ่มจากระบบสำหรับผู้ดูแล 1–5 คนต่อ Household

## แนวทางแก้ไข

PawRoutine รวมข้อมูลสัตว์เลี้ยง ตารางกิจวัตร งานประจำวัน และประวัติการดูแลไว้ในระบบเดียว ผู้ใช้สามารถสร้างกิจวัตร กำหนดผู้รับผิดชอบ ทำเครื่องหมายงาน และตรวจสอบประวัติย้อนหลังได้

## ขอบเขตและข้อจำกัด

- Phase 1 ไม่ใช้ AI/LLM
- ระบบไม่วินิจฉัยโรค
- ระบบไม่คำนวณหรือปรับขนาดยา
- ข้อมูลยาเป็นข้อมูลที่ผู้ใช้กรอกตามคำสั่งสัตวแพทย์
- ระบบเป็นเครื่องมือจัดการและบันทึกข้อมูล ไม่ใช่บริการทางการแพทย์

## สมมติฐานที่ต้องตรวจสอบ

1. ผู้ดูแลหลายคนมีปัญหาการสื่อสารเรื่องงานดูแลสัตว์
2. Today Board ช่วยลดการลืมและการทำซ้ำได้
3. ผู้ใช้ต้องการประวัติการดูแลย้อนหลัง
4. ผู้ใช้ยอมกรอกข้อมูล Routine ด้วยตนเอง หากระบบใช้งานง่าย
