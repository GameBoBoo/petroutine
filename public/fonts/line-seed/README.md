# LINE Seed web fonts

Source: LY Corporation, https://seed.line.me/

Original download packages (version 1.003):

- https://seed.line.me/src/images/fonts/LINE_Seed_Sans_EN.zip
- https://seed.line.me/src/images/fonts/LINE_Seed_Sans_TH.zip

The Regular and Bold WOFF2 files are unmodified; filenames were made descriptive.
License: SIL Open Font License 1.1, retained in OFL.txt from
https://github.com/line/seed/blob/main/OFL.txt.

The official static packages do not include Medium. The landing page requests
CSS 400/500/700; 500 falls back to the Regular face according to CSS font matching.
There is no fabricated Medium file or modified font. Fonts are served locally.
