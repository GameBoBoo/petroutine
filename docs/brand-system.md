# PetRoutine — มาตรฐานแบรนด์

อัปเดต 24 ตุลาคม 2026 ตามคำขอล่าสุด: ใช้ Google Sans ทั้งระบบ

## Typography

| บทบาท | ขนาดแนะนำ | น้ำหนัก | ระยะบรรทัด |
|---|---:|---:|---:|
| เนื้อหาหลักและฟอร์ม | 16px | 400 | 1.6–1.8 |
| ข้อความรองและข้อมูลรายการ | 14–15px | 400–500 | 1.6–1.8 |
| ปุ่ม เมนู และป้ายกำกับ | 14–16px | 500–600 | 1.5–1.7 |
| หัวข้อส่วน | 24–36px | 600 | 1.35–1.55 |
| หัวข้อใหญ่หน้าแรก | 42–64px ตามจอ | 600 | ประมาณ 1.4 |
| ตัวเลขเด่น ชื่อแบรนด์ และจุดเน้น | ตามบริบท | 700 | ตามบริบท |

ใช้ **Google Sans เพียงตระกูลเดียว** กับภาษาไทย ภาษาอังกฤษ ชื่อแบรนด์ หัวข้อ ปุ่ม ฟอร์ม ตัวเลข ข้อความตกแต่ง และเนื้อหาทั้งระบบ น้ำหนักที่ใช้คือ 400/500/600/700 ปิด `font-synthesis` เพื่อลดน้ำหนักปลอม ไม่ใช้ Mitr, Nunito, Mali, Prompt, Inter หรือ Poppins ใน UI อีกต่อไป ฟอนต์สำรอง `sans-serif` จะทำงานเฉพาะเมื่อไฟล์โหลดไม่ได้หรือข้อความใช้ชุดอักษรที่ไม่ได้เตรียมไว้

ไฟล์ WOFF2 ชุดไทย, Latin และ Latin Extended จาก Google Fonts อยู่ใน `public/fonts/google-sans/` พร้อม `OFL.txt`; `app/google-sans.css` กำหนด `@font-face` และ `app/globals.css` ใช้ทั่วเว็บ จึงไม่ต้องโหลดฟอนต์จากภายนอกขณะใช้งาน โลโก้ component ใช้สัญลักษณ์เส้นเดิมร่วมกับชื่อ PetRoutine ที่ render ด้วย Google Sans 700 หน้าในระบบใช้ component นี้เช่นกัน

แหล่งอ้างอิงฟอนต์: [Google Sans](https://github.com/googlefonts/googlesans), [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2), [SIL OFL 1.1](https://github.com/googlefonts/googlesans/blob/main/OFL.txt)

## สี

### Dark mode

โหมดมืดใช้พื้นกรมท่า `#151D29`, พื้นการ์ด `#202B3A`, พื้นยกระดับ `#263344` และเส้นขอบ `#3C4B5C` โดยให้ข้อความหลักเป็นครีม `#F6F1E9` และข้อความรอง `#AFBCC9` สีส้ม `#F59E0B` ยังคงเป็นจุดเด่นบนภาพประกอบและการ์ดต้อนรับ ส่วนปุ่มหลักใช้ส้มเข้ม `#B96108` เพื่อให้ตัวอักษรขาวอ่านชัด ป้ายและลิงก์ใช้ส้มอ่อน `#FFBD67` บนพื้นมืด ไม่ทำให้พื้นหลังทุกส่วนเป็นดำสนิทและไม่กลับสีภาพประกอบด้วย filter

ตัวสลับโหมดอยู่ที่แถบด้านบน หน้าแรก หน้า Login/Register และ Settings ค่าที่เลือกบันทึกใน `localStorage` ของอุปกรณ์ หากยังไม่เคยเลือกจะตามค่าระบบปฏิบัติการ ชุด override อยู่ใน `app/dark-mode.css` และต้องครอบคลุม Popup, dropdown, Today, Calendar, Pets สุขภาพ, Routines, History, Household และการแจ้งเตือนเมื่อเพิ่ม UI ใหม่

- **ส้มเป็นสีหลักของระบบ:** `#F59E0B` สำหรับพื้นที่แบรนด์และภาพประกอบ, `#C76C00` สำหรับรายละเอียดส้ม, `#A95300` สำหรับปุ่มหลักและข้อความส้มบนพื้นอ่อน, `#8A4300` สำหรับ hover ปุ่มหลัก ปุ่มสีเข้มช่วยให้ข้อความขาวอ่านชัด
- **กรมท่าเป็นสีเสริม:** `#1F2937` สำหรับหัวข้อ ข้อความหลัก และเส้นที่ต้องการคมชัด ใช้แผงกรมท่าขนาดใหญ่เท่าที่จำเป็น
- **พื้นหลัง:** `#FBF8F6` สำหรับ canvas, `#FFFAF4` สำหรับพื้นครีม, `#FEF3E7` สำหรับสถานะที่เลือก, `#ECE8E3` สำหรับเส้นขอบ
- **สีตามความหมาย:** เขียว `#47734E` ใช้กับงานที่เสร็จ/ผลสำเร็จ แดง `#B5473C` ใช้กับข้อผิดพลาด สีส้มใช้เป็นสีของการกระทำและแบรนด์

ตัวแปรสีหลักใน `app/globals.css` ใช้ส้ม/ครีม/กรมท่าทั่วหน้าภายใน ชื่อตัวแปร `--teal*` เป็นชื่อเก่าที่เก็บไว้เพื่อให้ component เดิมทำงานต่อ แต่ค่าชี้ไปที่ส้มแล้ว งานใหม่ควรใช้ชื่อ token ตามความหมายจริง

## Illustration

**Auth layout ล่าสุด:** Login และ Register ใช้กรอบเดียวสองฝั่งกว้างเท่ากัน ด้านซ้ายพื้นส้ม ด้านขวาฟอร์มสีขาว โดยให้สีต่อกันที่กึ่งกลาง ไม่มีช่องว่างหรือมุมมนด้านใน ทั้งสองฝั่งสูงเท่ากันบนจอคอมพิวเตอร์ มือถือเรียงบนล่างอยู่ในกรอบเดียว

**รูปแบบการ์ดล่าสุด:** หน้าแรกและแผงเรื่องราวของ Login/Register ใช้การ์ดสีส้ม `#F59E0B` มุมมนประมาณ 22–26px ตามภาพอ้างอิง ใช้ข้อความกรมท่าที่อ่านชัดและภาพ SVG อยู่ในพื้นที่การ์ด ลวดลายวงโค้งโปร่งเป็นองค์ประกอบรอง แต่ละจุดวางวงโค้งคนละตำแหน่งและใช้ภาพคนละฉาก การ์ดท้ายหน้าแรกใช้พื้นส้มและภาพสมุดกิจวัตรกับชามอาหาร กฎนี้อยู่ใน `app/brand-handdrawn.css`

**ข้อกำหนดล่าสุด: ไม่ใช้ภาพตกแต่งเดิมซ้ำหลายจุด** ผู้ใช้ต้องการให้แต่ละตำแหน่งมีฉากและองค์ประกอบที่ออกแบบใหม่ การเปลี่ยนสี ย่อขยาย หรือเพิ่ม/ลดสัตว์หนึ่งตัวไม่เพียงพอ ให้คงเฉพาะภาษาลายเส้น น้ำหนัก ความโค้ง และชุดสีร่วมกัน ภาพปัจจุบัน: Hero = คู่สัตว์กับใบไม้ (`CareIllustration`), CTA ท้ายหน้า = สมุดกิจวัตรและชามอาหาร, Login = แมวหลับบนเบาะใต้จันทร์, Register = บ้านกับหัวใจ (`CareSceneIllustration`) ข้อกำหนดนี้แทนข้อความเก่าที่ให้ใช้ภาพเดียวร่วมทุกหน้า

**อ้างอิงล่าสุดที่ผู้ใช้ยืนยัน:** ภาพสัตว์ตัวครีมใบหน้าเล็กกับกิ่งใบครีมบนพื้นส้ม และโลโก้ PetRoutine ที่แนบวันที่ 24 ตุลาคม 2026 ใช้ความโค้งและน้ำหนักเส้นของภาพนี้เป็นหลักทุกครั้งที่ redesign

- รูปตัวเป็นมวลสีครีมเรียบ หน้าตาเล็ก เส้นใบหน้ากรมท่า ไม่เพิ่มรายละเอียดกายวิภาคหรือใบหน้าใหญ่
- กิ่งใบโค้งเป็นธรรมชาติ ปลาย/มุมมน ความไม่สมมาตรพอดี ไม่ใช้เส้นสั่นถี่เพื่อเลียนแบบมือวาด
- ภาพหลักบน viewBox กว้าง 480 ใช้กิ่งใบ 4.5 หน่วย เส้นหน้า 3.5 หน่วย เส้นรอง 4 หน่วย เมื่อย่อเส้นย่อตามสัดส่วน; ไอคอนยังใช้ 2–2.5px ที่ขนาด 24px
- ภาพชุดกลางอยู่ที่ `components/CareIllustration.jsx` ใช้ร่วมกับ Landing, Login และ Register ในองค์ประกอบที่แตกต่างกัน
- Layout ล่าสุด: Landing ใช้ภาพหลักส้ม ฟีเจอร์การ์ดพื้นอ่อน FAQ เส้นแบ่ง และ CTA ครีม; Auth ใช้เรื่องราวและภาพบนพื้นครีมข้างการ์ดฟอร์มสีขาว Login/Register มีข้อความและจำนวนสัตว์ต่างกัน กฎใน `app/brand-handdrawn.css` แทนแนวทางภาพเก่าด้านล่าง

ภาพหลักของ Landing ใช้โปสเตอร์ส้มทรงโค้งพร้อมสุนัขและแมวลายเส้น มีการ์ดกิจวัตรสองใบและข้อความเรื่องการดูแลร่วมกัน แทนภาพจำลองตารางงานขนาดใหญ่ ให้ภาพประกอบและพื้นที่ว่างช่วยเล่าเรื่อง โดยใช้ Google Sans และสีตามมาตรฐานเดิม

- เส้นวาดมือ ปลายและมุมมน มีความไม่สมมาตรเล็กน้อย
- รูปทรงเรียบง่าย ไม่ใส่รายละเอียดมาก ไม่ใช้ 3D
- ตกแต่งอย่างพอดีและไม่บังข้อความ: เส้นใต้หัวข้อ กิ่งใบ และคู่สัตว์ที่ CTA หน้าแรก; หน้าเข้าสู่ระบบใช้ภาพเส้นบันทึกการดูแลแทน
- ภาพตกแต่งเป็น SVG, `aria-hidden`, ไม่รับ pointer events; มือถือวางภาพท้าย CTA ใต้ข้อความ

## Iconography

- กริด 24×24 น้ำหนักเส้น 2.25 หน่วย ที่ขนาด 24px เท่ากับ 2.25px
- ปลายเส้นและมุมมน โค้งไม่สมมาตรเล็กน้อย ใช้ชุดเดียวใน `components/Icon.jsx`
- ใช้ขนาด 16/18/20/24px ตามพื้นที่ ปุ่มยังมีพื้นที่กดอย่างน้อย 44px
- กรมท่า `#1F2937` เป็นหลัก ส้ม `#C76C00` สำหรับ selected/การกระทำสำคัญ พื้นครีม `#FFFAF4` หรือ `#FEF3E7`
- ไอคอนบนปุ่มสีเข้มใช้สีตามข้อความเพื่อให้เห็นชัด สีสถานะสำเร็จ/เตือนยังคงความหมายเดิม
- ไม่ผสมเส้นบางมาก เส้นหนามาก หรือไอคอน 3D ในชุดเดียวกัน

## ขอบเขตที่นำไปใช้แล้ว

ฟอนต์ Google Sans ใช้ทั่วเว็บ รวม Landing, Login/Register, Today และหน้าภายใน สีหลักระดับ token เป็นส้มแล้ว; CSS ของฟีเจอร์บางจุดยังมีสีสถานะเฉพาะและค่าสีเก่าที่ต้องค่อยตรวจตามหน้าจอ ชุดไอคอนกลางใช้ทั่วส่วนที่เรียก component เดียวกัน ชื่อทางเทคนิคของโปรเจกต์ยังไม่เปลี่ยน

## ความชอบที่ยืนยันแล้ว

ผู้ใช้ชอบสไตล์นี้และต้องการให้ยึดเป็นหลักทุกครั้งที่ redesign หรือเปลี่ยนสีในอนาคต: **ส้มเป็นหลัก กรมท่าเป็นสีเสริม พื้นครีม** ฟอนต์ Google Sans ทั้งระบบ เส้นวาดมือโค้งมนที่ใช้พอดี และไอคอนเส้นหนา 2–2.5px ที่มีบุคลิกเดียวกัน

หน้าเข้าสู่ระบบและสมัครสมาชิกใช้ `features/auth/AuthScreen.jsx` กับ `app/auth-brand.css`: คงโครงฟอร์มสองคอลัมน์ที่อ่านง่าย แผงด้านซ้ายใช้ส้มอ่อน `#FBE8CC` และรูปทรงส้ม `#F59E0B` ด้านหลังภาพเส้นกระดาษบันทึกใน `features/auth/AuthCareDoodle.jsx` กรมท่าใช้กับตัวอักษรและเส้นบนภาพ จึงต่างจากแผงส้มเข้ม/คู่สัตว์ของหน้าแรก มือถือวางฟอร์มต่อจากแถบแบรนด์สั้น ๆ
# UI ภายในระบบและรูปเริ่มต้นสัตว์เลี้ยง (24 ตุลาคม 2026)

- ใช้ Google Sans, พื้นครีม `#FBF8F6`, ส้ม `#F59E0B` เป็นสีแบรนด์ และกรมท่า `#1F2937` สำหรับข้อความในทุกหน้าหลังเข้าสู่ระบบ
- ปุ่มหลักใช้ส้มเข้ม `#A95300` เพื่อให้ข้อความสีขาวอ่านชัด เมนูที่เลือกใช้พื้นส้มอ่อนและกรอบบางรอบชิ้น การ์ดใช้ขอบอุ่น เงาเบา และมุมมนที่สม่ำเสมอ
- ไม่ใช้แถบสีที่ขอบซ้ายหรือมุมซ้ายของเมนู การ์ด โน้ต และรายการสถานะ ใช้พื้นหลังอ่อน กรอบรอบชิ้น และข้อความ/ป้ายสถานะแทน
- ลายเส้นตกแต่งเป็นเส้นโค้งปลายมนแบบวาดมือ ใช้น้อยและต่างรูปทรงกันในแต่ละตำแหน่ง ไม่ซ้ำภาพประกอบเดิมหลายจุด และต้องไม่ทับข้อมูลหรือปุ่ม
- รูปโปรไฟล์เริ่มต้นแมวและสุนัขจากไฟล์ที่ผู้ใช้ให้ อยู่ที่ `public/assets/brand/pet-avatar-cat.svg` และ `public/assets/brand/pet-avatar-dog.svg` ใช้ผ่าน `components/PetAvatar.jsx` ในรายชื่อและหน้าสัตว์เลี้ยง
- กฎภาพรวมหน้าภายในอยู่ใน `app/system-brand.css` ที่ import หลังชุด CSS ของหน้าแรกและหน้าเข้าสู่ระบบ เพื่อให้รูปแบบต่อเนื่องกันโดยไม่เปลี่ยนหน้าเหล่านั้น
