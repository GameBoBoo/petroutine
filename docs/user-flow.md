# User Flow และหน้าจอ

## เริ่มต้น

Landing → สมัคร/เข้าสู่ระบบ → สร้างบ้านหรือใส่รหัสเชิญ → เพิ่มสัตว์เลี้ยง → เปิด Quick Add → สร้างกิจวัตร → ตรวจทานและยืนยัน → ตรวจงานใน Today

## งานประจำวัน

Today → กรองงานของฉัน/ทุกคน สัตว์ และสถานะ → เห็นทั้งงานตามตารางและบันทึก Quick Add ของวันนี้ → เพิ่มหมายเหตุได้ → กดเสร็จ → ตรวจทานและยืนยัน → Undo ได้ภายใน 8 วินาทีและต้องยืนยันก่อนย้อนกลับ

ทางเลือกต่อหนึ่งงาน: Skip พร้อมเหตุผล, เลื่อนเวลาเฉพาะครั้ง, เปลี่ยนผู้รับผิดชอบเฉพาะครั้ง หากข้อมูลถูกสมาชิกคนอื่นเปลี่ยนก่อน ระบบแจ้ง conflict และโหลดข้อมูลล่าสุด

## บันทึกนอกตารางและสุขภาพ

เพิ่ม → เลือก “บันทึกสิ่งที่เกิดขึ้นแล้ว” หรือ “วางแผนล่วงหน้า” → บันทึกเช็กอิน/การดูแล/เหตุการณ์สุขภาพ หรือสร้างกิจวัตร/นัดหมาย → ข้อมูลแสดงใน Timeline ของสัตว์ หรือเป็นงานใน Today/Calendar ตามชนิดรายการ

## ตรวจสอบข้อมูล

- Today: งานที่ต้องทำวันนี้และการอัปเดตว่าเสร็จหรือข้าม
- ปฏิทิน: วางแผนและดู occurrence จริง/รายการที่กำหนดไว้ล่วงหน้า สูงสุด 42 วัน
- สัตว์เลี้ยง: ภาพรวม กิจวัตร สุขภาพ Timeline และรายงานสัตวแพทย์
- สุขภาพ: ภาพรวมแนวโน้ม, เช็กอินรายวัน, ข้อมูลสุขภาพประจำตัว (แพ้/ภาวะ/ยา/วัคซีน/นัด) และบันทึกเหตุการณ์ที่เกิดขึ้นแล้ว
- ประวัติงานดูแล: รายการ task ที่ complete/skip; เหตุการณ์สุขภาพและบันทึกอื่นดูได้ใน Timeline ของสัตว์
- เช็กอินสุขภาพ: เปิด Quick Add หรือ สัตว์เลี้ยง → สุขภาพ → เช็กอินรายวัน เลือกสัตว์และกรอกเฉพาะสิ่งที่สังเกตได้ รองรับเวลาย้อนหลัง แก้ไข และลบออกจากรายการใช้งานโดยรักษาประวัติ
- Learning Mode: อยู่ใน สุขภาพ → ภาพรวมสุขภาพ เพื่อดูจำนวนวันที่เก็บและความพร้อมของแต่ละ metric
- การแจ้งเตือน: เปิดกระดิ่งเพื่อดูงาน กำหนดวัคซีน/นัดหมาย และวันติดตาม Alert; ลบรายการที่ไม่ต้องการเห็นได้ และตั้งระยะเตือนสุขภาพได้ใน Settings
- Shared Monitoring: เปิด Alert → เลือกผู้ติดตาม วันติดตาม และหมายเหตุ → สมาชิกบ้านเห็นสถานะล่าสุดร่วมกันใน Alert/Activity/notification
- Vet Report: สัตว์เลี้ยง → “รายงานสัตวแพทย์” → เลือกช่วงวันที่ → เลือกหัวข้อ → ดาวน์โหลด PDF โดยตรงจาก browser

## บทบาทของหน้าหลัก

- Today ตอบว่า “วันนี้ต้องทำอะไร/ทำแล้วหรือยัง”
- Calendar ตอบว่า “วันไหนมีงานหรือนัดหมาย”
- Notifications สะกิดรายการที่ใกล้ถึงกำหนดและพาไป Today, วันนั้นใน Calendar หรือหน้าสุขภาพของสัตว์ตามประเภท
- History ตอบว่า “ใครทำหรือข้ามงานตามกิจวัตรเมื่อไร”
- Pet Timeline รวมเหตุการณ์ของสัตว์ทุกชนิด รวมบันทึกสุขภาพและรายการที่ลบออกจากรายการใช้งานโดยรักษาประวัติ

## Navigation

Desktop Sidebar และ mobile navigation ใช้ชื่อไทย: วันนี้ ปฏิทิน เพิ่ม สัตว์เลี้ยง และเพิ่มเติม โดยเพิ่มเติมรวมกิจวัตร ประวัติ บ้านและสมาชิก และตั้งค่า ไม่มีหน้า Change History ใน navigation

## การลบบ้าน

Household → เจ้าของบ้านเลือก “ลบบ้าน” → พิมพ์ชื่อบ้านให้ตรง → บ้านหายจากสมาชิกทุกคนและไม่แสดงรายการบ้านที่ลบใน UI โดยระบบยังรักษาข้อมูลเดิมไว้ภายใน

## กิจวัตรและการยืนยันล่าสุด (23 ตุลาคม 2026)

Routines → ค้นหาหรือกรองสัตว์ → ดูรายการครั้งละ 10 รายการ → เปิดรายละเอียดเพิ่มเติมเมื่อต้องการ → แก้ไข/เพิ่ม → ตรวจทาน → ยืนยันบันทึก หรือ ลบ → อ่านผลที่จะเกิดขึ้น → ยืนยันลบ ยกเลิกแล้วไม่มี mutation การลบใช้ soft archive ไม่ลบประวัติถาวร

Complete/Skip/Reopen/Undo, เลื่อนเวลา/มอบหมาย, สุขภาพ/ติดตาม และ Settings/สมาชิก/ความยินยอม AI มีหน้าต่างยืนยันก่อนเปลี่ยนข้อมูล ไม่มีส่วน Getting Started, Recovery Tools หรือรูป/ข้อมูลติดต่อใน UI ปัจจุบัน
