# Google Sans

The Thai, Latin, and Latin Extended WOFF2 subsets are served locally from Google Fonts (family `Google Sans`, version `v71`). They support variable weights 400–700. The original font project is [googlefonts/googlesans](https://github.com/googlefonts/googlesans). License: [SIL Open Font License 1.1](OFL.txt).

The CSS definitions live in `app/google-sans.css`. Keep the license with the font files when distributing the app.
