## ช่องที่ใช้การกรอกหรือปฏิทิน

- สร้างบ้าน/เข้าร่วมบ้าน: ชื่อบ้านหรือรหัสเชิญเป็นข้อความ ไม่ต้องใช้ dropdown
- ชื่อรายการ วิธีดูแล รายละเอียด หมายเหตุ ผลติดตาม และเหตุผลแก้การกดผิด: ข้อความอิสระ
- วันเวลาและช่วงวันที่: ใช้ปฏิทินและช่องเวลา
- น้ำหนัก: ตัวเลขหน่วยกิโลกรัม หน่วยคงที่ไม่ต้องให้เลือก
- ค่าตัวเลข/หน่วยในข้อมูลสุขภาพ: กรอกตามข้อมูลต้นทาง ระบบไม่คำนวณยา
- ลบรายการ ลบบ้าน เปลี่ยนรหัสเชิญ และย้อนกลับ: ข้อความยืนยัน/ปุ่ม ไม่เพิ่ม dropdown ที่ไม่จำเป็น

## เช็กอินรายวัน

คงตัวเลือกระดับเดิม: ไม่ได้บันทึก, น้อยกว่าปกติมาก, น้อยกว่าปกติ, ตามปกติ, มากกว่าปกติ, มากกว่าปกติมาก สำหรับอาหาร น้ำ กิจกรรม และการนอน

ขับถ่าย: ไม่ได้บันทึก, ปกติ, นิ่ม, เหลว, แข็ง, ยังไม่พบการขับถ่าย

อารมณ์: ไม่ได้บันทึก, ตามปกติ, สดใส, เงียบกว่าปกติ, กระสับกระส่าย, หงุดหงิด

ช่องว่างหมายถึงไม่มีข้อมูล ไม่ใช่ค่าปกติหรือศูนย์ ทุกประเภทกิจกรรมมีคำอธิบายสั้นใน dropdown และตัวเลือกสมาชิกแสดงอีเมลช่วยแยกคนชื่อซ้ำ

## ยืนยันก่อนดำเนินการ

- ฟอร์มกิจวัตร สัตว์ บ้าน Quick Add บันทึกสุขภาพ Passport เช็กอิน และ Settings ต้องทบทวนก่อนบันทึก
- Complete, Skip, Reopen, Undo, เลื่อนเวลา/เปลี่ยนผู้รับผิดชอบ และสถานะ/แผนติดตามสุขภาวะมี dialog บอกสิ่งที่จะเปลี่ยนก่อนส่งคำขอ
- นำสมาชิกออก โอนเจ้าของ เปลี่ยนรหัสเชิญ เปิด/ปิด AI และให้/ถอนความยินยอม AI ต้องยืนยัน
- ลบข้อมูลสุขภาพ Passport และเช็กอินใช้ `ConfirmationProvider`; สัตว์/กิจวัตรใช้ popup ยืนยันเดิม บ้านต้องพิมพ์ชื่อให้ตรง
- Dialog ของระบบมีปุ่มยกเลิก/ยืนยัน focus trap, Escape และคืน focus ยกเลิกแล้วไม่บันทึกข้อมูล ไม่ใช้ `window.confirm`
- “ลบ” หมายถึงนำออกจากข้อมูลใช้งานด้วย soft archive โดยประวัติยังอยู่ ไม่ใช่การลบถาวร
